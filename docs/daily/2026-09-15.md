### Teaching note and next task

A hash answers “is this the same mapping?” but not “is this mapping trustworthy?”
Chimera now lets a reviewer prove which mapping produced an assessment; later phases
must prove who/what defined that mapping and which procedure, thresholds and inputs it
refers to.
