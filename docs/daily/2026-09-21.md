## 15:12 Asia/Manila — Deterministic communications CSV ingestion

Current phases: P2 durable vertical and P3 engineering adapters are in progress; P0 scope
and P1 PM acceptance remain pending. Published AI-assisted implementation as
[`b329512`](https://github.com/lvlunario/project-chimera/commit/b329512a60add535f0916cf26231b7af2153ee72)
(`feat(core): ingest deterministic link telemetry`) by non-forced fast-forward to draft
PR #1; nothing merged.

Added a zero-dependency communications adapter for exact
`timestamp_utc,link_margin_db` CSV. It bounds source bytes to 1 MiB and samples to 10,000;
requires UTF-8 without BOM, an exact UTC timestamp grammar, strictly increasing times and
finite unpadded ASCII-decimal dB values; and hashes the exact source bytes with SHA-256.
Every callback reloads against the expected digest, so a changed file becomes an execution
error rather than a false engineering result. Exact `Decimal` comparison prevents a value
just below 3 dB from rounding upward into a false pass.

The synthetic vertical journals ingestion, verification configuration and the minimum-
margin check; exports completed evidence; saves/reopens it with its requirement binding;
and reproduces a COM-LINK-001 FAIL without callback replay. Portable evidence preserves
input hash/summary plus rule, threshold and unit. Added the public API, reference failing
fixture, `python -m examples.link_csv_demo`, installed-wheel proof, architecture decision
0013, ADAPT-001–006 traceability, README and manual instructions.

Actual final local verification on Linux/Python 3.12.14:

- `python -m unittest tests.test_telemetry -v`: 12/12 passed in 0.100 s.
- `python -m unittest discover -s tests -q`: 162/162 passed in 1.679 s.
- `python -m examples.link_csv_demo`: exact input identity recorded, journal/export/reopen
  completed, COM-LINK-001 failed as expected, ingestion/check callbacks each ran once.
- `bash scripts/verify_clean_install.sh`: isolated wheel build/install passed, including
  installed telemetry identity, exact failed threshold and all prior checks.
- `python -m compileall -q chimera examples tests` and `git diff --check`: passed.

Independent AI QA initially found four correctness boundaries: Unicode digits entered
through `\d`; permissive timestamp parsing accepted alternate forms; public constructors
could leak non-domain exceptions; and binary float rounded
`2.999999999999999999999999999999` to a false 3 dB pass. All were fixed with ASCII/exact
timestamp grammars, domain validation and exact decimal storage/comparison. Permanent
tests also cover exact byte/row limits, mutation between ingestion and check, durable
high-precision values and threshold configuration. Revised independent verification
passed 12 focused, 162 full, demo, clean install, compile and diff checks with no blocker.
No human approval or fictional staffing is recorded.

Engineering decision for Leo: a content hash proves that ingestion and checking used the
same bytes; exact decimal math proves a just-below-threshold value stays below threshold.
Neither proves the instrument or operator was trustworthy. That distinction prevents
both quiet file substitution and a numerical false pass without overstating provenance.

Limits/risks: raw CSV and individual failing rows are not copied into portable evidence;
SHA-256 is identity, not authenticity; paths are trusted local files and may follow
symlinks; journal/evidence databases are separate; no live/streaming radio, signed source,
fault injection, power-loss or production claim. Untrusted uploads must later be staged
as managed regular files. P2/P3 remain unaccepted. Hosted Python 3.11/3.12 evidence for
the published implementation head is pending inspection. No active engineering blocker.
