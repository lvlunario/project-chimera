Added a separate strict SQLite task journal, canonical plan and required operation
identity, deterministic sequential journaled runner, process-lifetime database ownership,
immediate finite-JSON result detachment, and callback-free inspect-only recovery. A
running marker commits before a callback; its terminal result commits before any later
callback. Exceptions fail, descendants block and independent work continues. Interrupt,
serialization and storage failures stop scheduling. An interrupted running task stays
unknown and the run becomes `needs_attention`; nothing automatically retries.

The journal is deliberately separate from the immutable completed-evidence database.
Adding tables to that exact version-1 schema would invalidate existing `EvidenceStore`
files without a tested migration. This preserves both contracts while P2 interfaces
settle, but the databases are not yet one atomic evidence bundle. Added a runnable
SIGKILL demonstration, installed-wheel verification, public API, manual, architecture
decision, traceability and current-state documentation. Tracker: issue #12; integration:
