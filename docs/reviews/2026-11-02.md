## 3–9 minutes — concept: evidence layers do not substitute for one another

Chimera deliberately keeps machine checks, browser automation and human judgment separate:

| Evidence layer | What it establishes | What it cannot establish |
|---|---|---|
| deterministic controls | inputs, verdicts, reports, hashes, restart and handoff agree under the declared synthetic cases | that a person understands the journey or that measured radio data is valid |
| rendered Chromium | native focus/activation, security headers, responsive overflow and download/reopen behavior work in one pinned browser environment | screen-reader interoperability, browser diversity, physical-device usability or human comprehension |
| actual operator review | labels, navigation, failure explanation and next action are understandable in the recorded environment | hidden technical properties that were not inspected or tested |
| phase disposition | Leo accepts, conditions, rejects or defers the bounded result | a merge, deployment, certification or expansion beyond the approved prototype |

Example: DASH-010 proves by structure and Chromium that the first Tab reveals `Skip to run
results`, Enter moves focus to the result heading, and each run link exposes verdict and
synthetic context. Only an operator can report whether that behavior is understandable and
whether the failure can be investigated without developer help.

Teaching note for Leo: think of these layers as an instrument self-test, a rehearsal in the
declared environment and the test conductor's sign-off. Each catches a different failure;
none can honestly fill in another layer's blank observation.
